
# Proyecto Integrador U4

## Optimización Inferencial del Rendimiento Agrícola

Aplicación interactiva desarrollada con Streamlit para analizar el rendimiento agrícola y la eficiencia del riego en cultivos de invernadero.

### Tecnologías utilizadas
- Python
- DuckDB
- Pandas
- NumPy
- Statsmodels
- SciPy
- Plotly
- Streamlit

### Funcionalidades
1. Simulación de 100 parcelas agrícolas.
2. Generación y extracción de datos mediante DuckDB.
3. Matriz de correlación de Pearson.
4. Modelo de regresión lineal múltiple OLS.
5. Evaluación de R² y RMSE.
6. Prueba t-Student de dos muestras independientes.
7. Intervalos de confianza del 95%.
8. Dashboard interactivo con cuatro visualizaciones.
9. Filtros dinámicos por tratamiento.
10. Exportación de datos en CSV.

### Ejecución local

```bash
pip install -r requirements.txt
streamlit run app.py
```
